# Temp Shelves Fix
A small plugin designed to prevent people from placing items into shelves, as to prevent a dupe.

# Demonstration
- https://www.youtube.com/watch?v=s4DYoub2pB0

# Installation
- You can find the pre-built binary at https://github.com/Cvahotni/TempShelvesFix/releases

# Building
- Clone the repository to your folder
- Open with IntelliJ Idea 2024.3 or any other compatible IDE.
- Create and configure a task for "maven package".
- If the build succeeds, the output files will be in target/
